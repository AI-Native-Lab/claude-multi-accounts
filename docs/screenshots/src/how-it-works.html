How Claude Multi-Accounts works

Claude keeps its sign-in in its data folder: the sessionKey cookies in Cookies and three keys in config.json. The app only ever moves those.

Open an account side by side main Claude keeps running

A second copy of Claude runs on the account's own folder, so two accounts are signed in at the same time.

1
Pick a saved account

Any account that isn't in the main Claude, or sign in to a new one.

2
Its folder becomes a data folder

Its saved keys move into a config.json there, with your language and theme.

3
Start a second Claude

A new copy of Claude, started with --user-data-dir set to that folder.

4
Use both

Refreshed tokens stay in that folder, so the account stays signed in for next time.

Switch the main Claude a few seconds

The main Claude restarts signed in to another account. Its settings, extensions and Code sessions stay where they are.

1
Quit Claude

Like ⌘Q. Never forced: if Claude won't quit, nothing changes.

2
Save its sign-in

The live cookies and keys go to the folder of the account they belong to, after a backup.

3
Put the other in place

The target account's saved cookies and keys replace them. Nothing else is touched.

4
Reopen Claude

Claude opens already signed in. Nothing is sent to Anthropic.

The main Claude

~/Library/Application Support/Claude/ Cookies ← claude.ai sign-in config.json ← tokens, account id … settings, extensions, sessions

Each saved account

~/.claude-multi-accounts/ accounts.json names and order accounts/<id>/ its sign-in, and its own window's data once opened backups/ the last 20 live sign-ins
✓
Each sign-in lives in one place at a time: the main Claude, its folder, or the window running on that folder. An account open in its own window can't be switched to or removed until that window closes, and nothing is ever force-quit.
